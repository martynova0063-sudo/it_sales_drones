# Инструкция: Установка и авторизация Tailscale на Linux (Ubuntu)

Цель: Создать виртуальную сеть, где все твои устройства будут иметь статические "частные" IP-адреса, доступные друг другу через интернет.

## Шаг 1: Создание аккаунта Tailscale (если еще нет)

1. Открой браузер и перейди на сайт: https://tailscale.com/register/
2. Зарегистрируйся, используя свой аккаунт Google, Microsoft или GitHub.
3. Ты попадешь в панель управления Tailscale (Dashboard). Пока она будет пустой.

## Шаг 2: Установка клиента Tailscale на Linux (Ubuntu)

Открой терминал на своем Ubuntu ПК (это будет либо ПК с ПУ, либо ПК с Нодой).

1. Добавление репозитория Tailscale:
    ```bash
    curl -fsSL https://tailscale.com/install.sh | sh
    ```
   * Эта команда скачает и запустит скрипт, который добавит репозиторий Tailscale в твою систему и установит ключ GPG.

2. Установка клиента Tailscale:
    ```bash
    sudo apt update
    sudo apt install tailscale
    ```
   * Эта команда обновит список пакетов и установит сам клиент Tailscale.

## Шаг 3: Авторизация устройства в твоей Tailscale-сети

 После установки клиент запущен, но еще не подключен к твоей виртуальной сети.
1. Подключение к Tailscale:
    ```bash
    sudo tailscale up
    ```
2. Авторизация: Эта команда выведет в терминал URL-ссылку, похожую на:
    `To authenticate, visit: https://login.tailscale.com/a/abcXYZ...`
3. Скопируй эту ссылку и вставь её в браузер.
4. В браузере ты попадешь на страницу авторизации Tailscale. Подтверди подключение нового устройства к своей сети (кнопка "Connect" или "Authorize").
5. После авторизации в браузере вернись в терминал. sudo tailscale up должна завершиться успешно.

## Шаг 4: Проверка подключения и IP-адреса

1. Проверка статуса Tailscale:
    ```bash
    tailscale status
    ```

   * Ты увидишь список своих подключенных устройств, и у каждого будет свой виртуальный IP-адрес, начинающийся на 100.. Например, **100.X.Y.Z**.

2. Проверка IP-адреса этого устройства:
    ```bash
    tailscale ip -4
    ```

   * Это выведет только IPv4 адрес Tailscale. Запомни его (**100.A.B.C**). Он понадобится для конфига, если будем использовать `STATIC_IP_ADDRESS` в режиме **Tailscale**.
    
   * PS. Для проверки подключенных устройств: `https://login.tailscale.com/admin/welcome`

## Шаг 5: Повторить для всех устройств

   * Повтори Шаги 2-4 на каждом компьютере, который будет служить Нодой, и на компьютере, где будет запущен ПУ.

   * Все устройства должны быть авторизованы **в одном и том же аккаунте** Tailscale.

## Важные моменты:

   * **Виртуальные IP-адреса**: Все устройства в твоей Tailscale-сети будут "видеть" друг друга по своим `100.X.Y.Z` IP-адресам, даже если они находятся в разных городах за разными роутерами.

   * **Фаервол**: Tailscale сам обходит большинство NAT и фаерволов.

   * **Безопасность**: Весь трафик внутри Tailscale-сети зашифрован.


## Добавление нового пользователя:

Чтобы пригласить коллегу, зарегистрировавшего свой Tailscale, нужно перейти на вкладку "Users" (Пользователи):
1. Открыть свой Dashboard: `https://login.tailscale.com/admin/machines`
2. В верхней части экрана (рядом с **"Machines"**) найти и нажать на вкладку **"Users"**.
3. На открывшейся странице **"Users"** найти кнопку **"Invite user"** (Пригласить пользователя) или "Add user" (Добавить пользователя).
4. Нажать её. Появится диалоговое окно, где нужно будет ввести email-адрес коллеги (тот email, который он использовал для регистрации своего аккаунта GitHub/Google/Microsoft).
5. Отправить приглашение.

Что произойдет дальше:
1. Коллега получит email от Tailscale с приглашением присоединиться к сети.
2. Когда он примет это приглашение, его устройства, которые он авторизовал в своем аккаунте, появятся в разделе **"Machines"** (Устройства) на твоем Dashboard.
3. Они будут помечены как **"Needs Approval"** (Требует одобрения) или будут находиться в секции **"Other Users"** (Другие пользователи).
4. Нужно нажать кнопку **"Add to network"** (Добавить в сеть) или **"Move to network"** (Переместить в сеть) рядом с его устройством на своем Dashboard.

* Только после одобрения его устройства, оно станет частью ТВОЕЙ Tailscale-сети, и вы сможете общаться.
