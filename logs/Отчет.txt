Отчет по Файлам, Функциям и Зависимостям

Файл	Тип	Назначение (Что делает)	Входные данные (Зависит от)	Выходные данные
=======================================================================================
Файл:
ml.sh

Тип:
Bash

Назначение (Что делает):
Скрипт-оркестратор Фазы 1 (Создание данных).
Запускает MATLAB в пакетном режиме, устанавливает пути и вызывает run_dataset_script.

Входные данные (Зависит от):
Исполняемый файл MATLAB, Файлы меток (*.mat) в Video_V/Video_IR.

Выходные данные:
Запуск процесса run_dataset_script.

=======================================================================================
Файл:
run_dataset_script.m

Тип:
MATLAB

Назначение (Что делает):
Function	Фаза 1: Извлечение Кадров. Читает все .mat метки, извлекает каждый кадр из соответствующих видео, связывает кадры с метками и сохраняет результат в батчах, управляя памятью.

Входные данные (Зависит от):
Файлы меток (*.mat), Видеофайлы (*.mp4/*.avi), Конфигурация батчей (batchSize=1).

Выходные данные:
644 файла Training_data_V_Batch_X.mat, ~178k PNG-файлов в Training_data_V.

=======================================================================================
Файл:
exp_csv.sh

Тип:
Bash

Назначение (Что делает):
Скрипт-оркестратор Фазы 2 (Экспорт). Запускает MATLAB для выполнения export_yolo_prep.

Входные данные (Зависит от):
Исполняемый файл MATLAB, Training_data_V_Batch_X.mat (от Фазы 1).

Выходные данные:
Запуск процесса export_yolo_prep.

=======================================================================================
Файл:
export_yolo_prep.m

Тип:
MATLAB

Назначение (Что делает):
Function	Фаза 2: Объединение и Экспорт. Загружает все 644 файла Training_data_V_Batch_X.mat, объединяет их в одну большую таблицу MATLAB и экспортирует в чистый формат CSV.

Входные данные (Зависит от):
644 файла Training_data_V_Batch_X.mat.

Выходные данные:
1 файл Training_data_FINAL_EXPORT.csv.

=======================================================================================
Файл:
yolo_converter.py

Тип:
Python Script

Назначение (Что делает):
Фаза 3: Финальная Конвертация. Читает объединенный CSV, нормализует BBoxes в формат YOLO, создает файлы .txt и перемещает/визуализирует PNG-файлы.

Входные данные (Зависит от):
Training_data_FINAL_EXPORT.csv, PNG-файлы в Training_data_V.

Выходные данные:
train/images (PNG), train/labels (TXT), train/visualize (Визуализация).

=======================================================================================
Файл:
Training_data_FINAL_EXPORT.csv

Тип:
CSV

Назначение (Что делает):
Промежуточный/Финальный набор данных. Содержит все BBoxes в абсолютных пиксельных координатах, привязанных к именам PNG-файлов.

Входные данные (Зависит от):
export_yolo_prep.m

Выходные данные:
yolo_converter.py
