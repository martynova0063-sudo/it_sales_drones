# 🛡️ Распределённая система обнаружения дронов (Drone Detection System)

## Описание проекта
Данный программный комплекс предназначен для обнаружения беспилотных летательных аппаратов (БПЛА) и других объектов в видеопотоках с камер наблюдения в режиме реального времени. Система использует нейросеть YOLO для детекции и архитектуру "Edge-Cloud" для распределенной обработки данных.

## Цели системы
*   **Автономная детекция:** Обработка видеопотоков происходит на периферийных устройствах (Нодах), минимизируя нагрузку на сеть.
*   **Централизованный мониторинг:** Единый Пульт Управления (ПУ) собирает алерты (тревоги) со всех подключенных Нод.
*   **Оперативное реагирование:** Визуальное и звуковое оповещение оператора, дублирование уведомлений в Telegram.
*   **Архивация событий:** Автоматическая запись и возможность скачивания видеофрагментов зафиксированных инцидентов.

## Архитектура
Система состоит из двух основных компонентов:

1.  **Нода (Edge Node):**
    *   Подключается к источнику видео (IP-камера, RTSP/RTMP/HLS поток, локальный видеофайл, локальная вебкамера).
    *   Выполняет детекцию объектов (YOLOv8).
    *   Ведет локальную запись чанков видео.
    *   При обнаружении угрозы отправляет алерт на ПУ.
    *   Обеспечивает MJPEG-стрим для визуального контроля.

2.  **Пульт Управления (ПУ / Dashboard):**
    *   Веб-интерфейс (на базе Gradio) для оператора.
    *   Принимает и отображает алерты.
    *   Позволяет просматривать видеопоток с конкретной Ноды по запросу.
    *   Управляет скачиванием архивных записей с Нод.
    *   Отображает галерею подключенных камер и их статусы.

## Быстрый старт (для разработчиков)

1.  Установите зависимости: `pip install -r requirements.txt`.
2.  Убедитесь, что в системе установлен `ffmpeg` и `ffprobe`.
3.  Настройте `configs/stream_sources.json` и `.env`.
4.  Запустите Пульт Управления: `python3 app.py`.
5.  Запустите Ноду: `python3 node.py --select <camera_id>`.

Подробная инструкция по эксплуатации находится в файле [USER_MANUAL.md](USER_MANUAL.md).
1. Настроить хранение ключей. (NODE_AUTH_KEY, CLIENT_AUTH_KEY)
2. Создать верификацию ноды на пульте. (Проверка ключа ноды)
3. Расширить данные событий. (Добавить скорость, прогноз)
4. Создать общую шину событий. (для логов, ТГ, API)
5. Добавить историю событий (REST API)
6. Добавить события в реальном времени. (WebSocket API)
7. Ускорить работу ноды. (запустить Алерты через treading, чтобы не тормозили процесс)
8. Подключить трекер BoT-Sort.
9. Визуализировать предсказание направления движения (на основе прогнозов на каждом шаге)
10. Частично (то что нашел): Нарезать видео с дронами для датасета (по договоренности с Гинтарасом)
11. Добавил текущую статистику предсказаний (прогноза движений)
